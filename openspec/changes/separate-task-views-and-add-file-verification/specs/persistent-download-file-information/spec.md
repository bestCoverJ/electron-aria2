## ADDED Requirements

### Requirement: 单条历史记录永久删除

系统 SHALL 允许用户永久删除单条历史记录，并 MUST 保留对应的已下载文件。

#### Scenario: 删除单条历史记录

- **WHEN** 用户确认删除某条历史记录
- **THEN** 该记录从持久化状态和历史列表移除且本地文件不被删除

### Requirement: 恢复真实文件信息

系统 SHALL 为历史任务恢复已持久化文件列表和大小，并在旧快照文件大小为 0 或文件列表为空时尝试通过可访问的本地文件补全真实信息。

#### Scenario: 恢复旧版单文件历史

- **WHEN** 旧历史快照的文件数组为空或大小为 0 且本地文件仍存在
- **THEN** 文件选项卡显示该文件，任务和文件大小显示本地真实字节数而非 0 B

#### Scenario: 历史文件不可访问

- **WHEN** 历史记录对应文件已移动或删除
- **THEN** 系统保留历史记录并明确显示文件不可用，不伪造文件大小或哈希

### Requirement: 文件类型与 SHA-256 信息

系统 SHALL 在文件选项卡显示每个文件的类型，并 SHALL 在任务完成后以流式方式计算和持久化 SHA-256 哈希。

#### Scenario: 下载尚未完成

- **WHEN** 用户查看未完成任务的文件选项卡
- **THEN** 系统显示文件类型且 SHA-256 区域提示任务完成后计算

#### Scenario: 完成任务哈希计算中

- **WHEN** 任务已完成但文件 SHA-256 尚未计算完成
- **THEN** 系统显示正在计算占位而不显示空值或错误哈希

#### Scenario: 完成任务哈希可用

- **WHEN** 完成文件的 SHA-256 已计算并持久化
- **THEN** 文件选项卡显示完整 64 位十六进制 SHA-256，应用重启后无需重新计算即可恢复
